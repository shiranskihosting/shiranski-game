# המטבח של שירנסקי מארח

משחק אינטראקטיבי ללקוחות שירנסקי מארח.

קישור קבוע: https://sorekshiran81-droid.github.io/shiranski-game/

## איך מתעדכן
כל שינוי שנשמר ב-main עובר קודם בדיקה אוטומטית (`tests/run.js`, בערך 50 בדיקות בגודל טלפון).
רק אם כל הבדיקות עוברות, האתר מתעדכן. אם משהו נכשל, הגרסה הקודמת נשארת אצל הלקוחות.

## איפה מה
- `js/data.js` – כל התוכן: מנות הגשר, שאלות, משפטי נכון/לא נכון, תמונות, פרסי הגלגל
- `js/app.js` – לוגיקת המשחקים והגלגל
- `js/fx.js` – צלילים וזיקוקים
- `img/` – תמונות המנות (720px) · `img/ui/` – איורי הקטגוריות (Canva, וקטורי)
- גלגל המזל: ההגרלה והקוד נוצרים בתרחיש Make "שירנסקי – גלגל המזל", ונרשמים בגיליון הפרטי "קודי פרסים – שירנסקי מארח"
